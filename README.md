## 🎨 Project Overview & Features

참고하신 프리미엄 영상 에이전시의 세련되고 품격 있는 감성을 극대화하여 제작된 반응형 단일 페이지 포트폴리오 웹사이트입니다.

### 1. 🌟 주요 기능 (Main Features)
* **시네마틱 히어로 비주얼 배너 (Cinematic Hero Banner)**
  * 상단에 아름다운 시네마틱 드론 영상이 소리 없이 무한 루프로 자동 재생되며 방문자의 시선을 압도합니다.
* **스마트 카테고리 필터링 (Smart Category Filtering)**
  * `All`, `Commercial`, `Short Film`, `Music Video` 탭을 제공합니다. 
  * 탭 전환 시 카드가 흐려졌다가 정렬되는 **프리미엄 페이드-인/아웃 모션**이 적용되었습니다.
* **원클릭 인스턴트 라이트박스 플레이어 (Instant Lightbox Player)**
  * 썸네일 카드를 클릭하는 즉시 고급스러운 어두운 반투명 블러 백그라운드 위로 비디오 플레이어 모달이 열리고 재생됩니다.
  * 창을 닫거나 ESC 키를 누르면 비디오 객체가 메모리에서 해제되어 완벽히 멈춥니다.
* **화면 확대 및 시네마 극장 모드 (Theater & Fullscreen Mode)**
  * **극장 모드 (Theater Mode)**: 영상 우측 상단의 `극장 모드` 버튼을 누르면 플레이어 가로 폭이 화면에 맞게 최대로 늘어나 시원한 감상이 가능합니다.
  * **전체 화면 (Fullscreen)**: HTML5 API를 기반으로 PC나 모바일 윈도우 스크린 전체를 가득 채우는 풀스크린 감상을 지원합니다.
* **검색 최적화 (SEO Integration)**
  * 구글 및 네이버 등의 포털 사이트 노출을 위한 상세 설명, 키워드, 그리고 오픈그래프(OG) 메타태그가 빈틈없이 내장되어 있습니다.
